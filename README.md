# 放榜 · 중국 드라마 순위

도우반(豆瓣) 데이터를 매일 한 번 자동으로 수집해서, **품질 순위**(평점순)와
**화제성 순위**(인기순)를 장르별로 보여주는 정적 웹사이트입니다.

GitHub Pages(호스팅) + GitHub Actions(자동 갱신) 조합으로 **비용 없이** 돌아갑니다.

---

## 무엇이 되고 무엇이 안 되나

**되는 것**

- 매일 1회 자동 갱신 (사람이 아무것도 안 해도 됨)
- 품질 / 화제성 두 가지 순위 전환
- 장르별 필터 (현대극·역사극·로맨스·무협·서스펜스)
- 전날 대비 순위 변동 표시 (▲ ▼ NEW)
- 날짜별 아카이브 — 갱신이 쌓일수록 월별로 골라 볼 수 있게 됩니다
- 중국어 제목의 한글 발음 표기 자동 생성
- 수집 실패 시 직전 데이터 유지 (사이트가 비지 않음)

**안 되는 것**

- 방문자가 버튼을 눌러 **그 자리에서** 최신 데이터를 가져오는 것.
  GitHub Pages는 정적 파일만 제공하므로, 요청에 반응해 실시간으로 수집하려면
  Vercel·Railway 같은 별도 서버가 필요합니다.
- 몇 분 단위의 잦은 갱신. 상대 사이트 차단 위험이 있어 하루 1회로 맞췄습니다.
- 회원 로그인, 사용자별 즐겨찾기 서버 저장.

## 설치 (10분)

### 1. 저장소 만들기

GitHub에서 새 저장소를 만듭니다. **반드시 Public(공개)으로 만드세요.**
비공개 저장소는 Actions 실행 시간이 월 2,000분으로 제한되고,
무료 요금제에서는 Pages를 쓸 수 없습니다.

### 2. 파일 올리기

이 폴더의 내용을 통째로 저장소에 올립니다. 구조는 다음과 같습니다.

```
.
├── index.html                    # 웹페이지
├── requirements.txt
├── 1_최초설치.bat                # 윈도우용 - 라이브러리 설치
├── 2_실행.bat                    # 윈도우용 - 수집 + 미리보기
├── 3_깃허브에_올리기.bat          # 윈도우용 - 수집 + 업로드
├── data/                         # 수집 결과가 쌓이는 곳
│   └── history/
├── scripts/
│   ├── fetch_rankings.py         # 수집 스크립트
│   └── hangul.py                 # 병음 → 한글 변환
└── .github/workflows/update.yml  # 매일 자동 실행
```

### 3. Actions에 쓰기 권한 주기

저장소 **Settings → Actions → General → Workflow permissions** 에서
**Read and write permissions** 를 선택하고 저장합니다.
이걸 안 하면 수집은 되지만 결과를 커밋하지 못해 갱신이 반영되지 않습니다.

### 4. Pages 켜기

**Settings → Pages → Build and deployment** 에서
Source를 **Deploy from a branch**, 브랜치를 **main / (root)** 으로 지정합니다.

1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속됩니다.

### 5. 첫 수집 실행

**Actions 탭 → Update rankings → Run workflow** 를 눌러 한 번 수동 실행합니다.
처음에는 `data/rankings.json` 이 없어서 사이트가 "데이터 없음"으로 보이는 게 정상이며,
이 실행이 끝나면 목록이 나타납니다.

이후로는 매일 아침 6시(한국 시간)에 자동으로 돌아갑니다.

## 내 PC에서 먼저 돌려보기

GitHub에 올리기 전에 로컬에서 확인해 보는 것을 **권장합니다.**
도우반이 데이터센터 IP를 차단하는 경우가 있어서, 집 인터넷에서는 되는데
GitHub 서버에서는 막히는 일이 실제로 있습니다. 미리 확인해 두면 좋습니다.

### 윈도우 — 배치파일로 (쉬움)

폴더에 있는 배치파일을 순서대로 더블클릭하면 됩니다.
Python 3.9 이상이 설치돼 있어야 하고, 설치할 때 **"Add Python to PATH"** 를
체크했어야 합니다.

| 파일 | 언제 쓰나 | 하는 일 |
|---|---|---|
| `1_최초설치.bat` | 처음 한 번만 | 필요한 라이브러리를 설치합니다 |
| `2_실행.bat` | 볼 때마다 | 순위를 수집하고 브라우저로 사이트를 엽니다 |
| `3_깃허브에_올리기.bat` | 필요할 때 | 수집한 데이터를 깃허브에 올립니다 |

`2_실행.bat` 을 실행하면 검은 창이 뜨고, 수집이 끝나면 브라우저가 자동으로
`http://localhost:8000` 을 엽니다. **이 검은 창은 닫지 마세요.**
창을 닫으면 서버가 꺼져서 사이트도 안 열립니다. 다 봤으면 창에서 `Ctrl+C` 를
누르거나 창을 닫으면 됩니다.

`3_깃허브에_올리기.bat` 은 GitHub Actions가 차단당했을 때 쓰는 대안입니다.
자세한 건 아래 "차단됐을 때" 항목을 보세요.

### 맥·리눅스 — 터미널로

압축을 푼 폴더에서 터미널을 열고:

```bash
# 1) 필요한 라이브러리 설치 (처음 한 번만)
pip install -r requirements.txt

# 2) 데이터 수집 (연도는 바꿔도 됩니다)
python scripts/fetch_rankings.py 2026

# 3) 로컬 서버 실행
python -m http.server 8000
```

그다음 브라우저에서 **http://localhost:8000** 으로 접속합니다.

> **`index.html` 파일을 그냥 더블클릭하면 안 됩니다.**
> 이 페이지는 `data/rankings.json` 을 불러오는데, `file://` 로 열면 브라우저 보안
> 정책(CORS) 때문에 차단되어 "데이터 없음"만 보입니다. 반드시 서버를 띄우고
> `localhost` 로 접속해야 합니다. (배치파일은 이걸 알아서 해 줍니다.)

수집이 잘 되면 이런 로그가 나옵니다.

```
[06:00:03]   현대극·현실주의     평점순: 20건
[06:00:07]   현대극·현실주의     인기순: 20건
...
[06:01:12] 완료: 63편 저장 · 상태 ok
```

한글 발음 변환만 따로 시험해 보고 싶다면:

```bash
python scripts/hangul.py
```

## 차단됐을 때 (HTTP 403 / 429)

수집 로그에 `HTTP 403 차단 응답` 이 뜨면 도우반이 요청을 거부한 것입니다.
스크립트는 3회 연속 차단되면 더 두드리지 않고 즉시 멈춥니다.

**내 PC에서도 403이 나는 경우**

- 잠시 뒤(수십 분~몇 시간) 다시 시도해 보세요. 일시적 차단인 경우가 많습니다.
- 브라우저에서 `movie.douban.com` 에 접속되는지 확인하세요. 사이트 자체가
  안 열린다면 네트워크나 지역 문제입니다.

**내 PC는 되는데 GitHub Actions에서만 403이 나는 경우**

이게 가장 흔한 상황이고, 안타깝지만 GitHub 쪽에서 우회할 방법은 마땅치 않습니다.
현실적인 선택지는 세 가지입니다.

1. **로컬에서 돌리고 결과만 올리기** — 가장 확실한 방법입니다.
   윈도우는 `3_깃허브에_올리기.bat` 을 더블클릭하면 수집부터 업로드까지 한 번에
   끝납니다. 맥·리눅스는 아래를 실행하세요.
   ```bash
   python scripts/fetch_rankings.py 2026
   git add data && git commit -m "데이터 갱신" && git push
   ```
   자동은 아니지만 사이트는 정상 동작하고, 순위 변동·아카이브 기능도 그대로
   쌓입니다. 윈도우 작업 스케줄러에 `3_깃허브에_올리기.bat` 을 등록해 두면
   PC가 켜져 있을 때 자동으로 돌게 만들 수도 있습니다.

2. **갱신 주기를 더 늘리기** — 주 1~2회로 줄이면 차단 확률이 낮아질 수 있습니다.
   `.github/workflows/update.yml` 의 `cron` 을 `0 21 * * 1` (매주 월요일) 등으로
   바꿉니다.

3. **다른 데이터 출처로 바꾸기** — `scripts/fetch_rankings.py` 의 `fetch()` 만
   교체하면 나머지(순위 계산·한글 변환·아카이브·화면)는 그대로 재사용됩니다.

수집이 실패해도 사이트는 직전에 성공한 데이터를 계속 보여주고, 상단에
"최신 수집 실패" 표시만 뜹니다. 방문자가 빈 화면을 보는 일은 없습니다.

## 다른 사람에게 공유하기

Pages 주소를 그대로 알려주면 됩니다. 받는 사람은 설치할 것이 없고,
아이폰 사파리에서 열어 **공유 → 홈 화면에 추가** 를 누르면 앱처럼 쓸 수 있습니다.

## 자주 손볼 만한 곳

| 하고 싶은 것 | 고칠 파일 / 위치 |
|---|---|
| 갱신 시각 바꾸기 | `.github/workflows/update.yml` 의 `cron` (UTC 기준) |
| 장르 추가·변경 | `scripts/fetch_rankings.py` 의 `GENRES` |
| 수집 편수 늘리기 | 같은 파일의 `PAGE_SIZE` (20 → 30 등) |
| 대상 연도 바꾸기 | 워크플로 실행 명령에 인자 추가: `python scripts/fetch_rankings.py 2025` |
| 색상·글꼴 | `index.html` 상단의 `:root` 변수 |

## 알아둘 점

도우반은 공식 공개 API를 제공하지 않습니다. 이 프로젝트는 도우반 웹사이트가
내부적으로 사용하는 공개 엔드포인트를 호출하며, 다음을 전제로 만들어졌습니다.

- 하루 1회, 요청 사이에 3초 이상 간격을 두어 부담을 최소화합니다.
- 응답 구조가 바뀌거나 차단되면 수집이 실패할 수 있습니다.
  이 경우 직전 데이터를 유지하고 화면 상단에 "수집 실패" 표시가 뜹니다.
- 상업적 재배포나 대량 수집 용도로 확장하는 것은 권하지 않습니다.

한글 제목은 국립국어원 외래어 표기법(중국어)을 근사 구현한 자동 변환이라,
이미 굳어진 통용 표기와 다를 수 있습니다. 특정 제목을 고정하고 싶다면
`scripts/hangul.py` 의 `WHOLE` 사전에 예외를 추가하세요.
